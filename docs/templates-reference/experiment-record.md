# Experiment Record Template

Use this template to record research, spikes, and prototyping experiments.

```yaml
---
id: EXP-0000
title: Short title
status: active # Options: running | stopped | extended | graduated
owner:
date: YYYY-MM-DD
maturity: R0 | R1 | R2 | R3
---
```

## Question

What are we trying to find out?

## Time-box

Target completion date and effort limit.

## Method

Experimental method and test procedure.

## Setup

Versions, hardware, configuration and data locations.

## Results

Include negative results and unexpected behavior.

## Conclusion

Summary of findings.

## Decision and next step

Stop, extend (with reason), or graduate.

## Reproduction

Commands and scripts needed to repeat this experiment.
